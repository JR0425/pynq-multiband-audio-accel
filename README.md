# PYNQ Multiband Audio Accelerator

Real-time multi-band audio processing acceleration platform on PYNQ-Z2.

## Structure
- src/     - HLS, RTL, and Python source code
- sim/     - Simulation and verification
- build/   - Build scripts (Vivado, Vitis HLS)
- board/   - Overlay files, Jupyter notebooks, board scripts
- data/    - Test audio, measured results, figures
- skill/   - LLM collaboration skill package
- report/  - Design report, collaboration log, poster
