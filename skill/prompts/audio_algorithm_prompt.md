# 音频处理算法常用提示词工作流

## 场景一：设计 FIR 滤波器
- **提示词**：帮我用 Python scipy.signal.firwin 设计一个 65 抽头的 FIR 低通滤波器，截止频率 600Hz，采样率 48000Hz，并画出频谱响应。
- **要点**：需要明确抽头数（影响阶数）、截止频率和采样率。

## 场景二：FFT 频谱分析
- **提示词**：对一段 10 秒的 48kHz 语音信号做 FFT 分析，要求只显示 0-2000Hz 范围，纵坐标归一化到 0-1.5，横坐标显示频率(Hz)。
- **要点**：必须强调去直流 `x = x - np.mean(x)`，防止 0Hz 出现巨大尖峰；强调归一化 `/ n * 2`。

## 场景三：动态范围压缩 (DRC)
- **提示词**：实现一个助听器场景下的动态范围压缩算法，设定阈值为 0.1，压缩比为 0.7，对每个频段独立压缩。
- **要点**：使用 `np.where` 判断阈值，对超出部分乘以压缩比，模拟“小声放大，大声压小”。
