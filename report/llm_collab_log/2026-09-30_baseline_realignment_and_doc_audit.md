【哪里错了】

· **AI 的问题（"加速比"这个对照一直是假的）**

  原来只打算改一处：基线脚本里还写着旧边界 300/600/1000。改到一半才意识到
  这不是笔误，是**两边根本不在做同一件事**：

  | | 软件基线（原来） | 硬件核（现在） |
  |---|---|---|
  | 采样率 | 跟着音频文件走，**44100** | **48000** |
  | 边界 | 300 / 600 / 1000 | 500 / 1000 / 2000 |
  | 设计法 | 每段各自 `firwin` 一个带通 | 3 个低通相减 |
  | 数值 | float | int16 / Q1.15 |

  **"加速比"这个词的前提就是两边做同一件事。** 四个维度全不一样，
  那个对照跑出来的数没有任何意义。现在全部从 `band_design.py` 取，
  基线先重采样到 48 kHz。

  更值得记的是：**那个脚本第一行写着"存在的唯一理由是做加速比对照"，
  但全仓库没有任何地方测过 CPU 耗时** —— 这个理由一直是空的。已补上计时和实时倍率。

· **AI 的问题（只打算改一个文件，没想到要按"类"去搜）**

  同类问题有六七处，我是改到第二个才反应过来该按"过期参数"这个类去搜一遍，
  而不是想起一个改一个。后来做全仓库通读，又查出 **12 处**，其中三处会直接让人做错：

  1. `README.md` 顶上的"选定配置"资源数，写的是**旧版**那一组
     （2493 LUT / 70 DSP / +0.639 ns），不是当前选定的
     （3962 LUT / 202 DSP / +1.624 ns）—— 差了一倍还多。
  2. 两份调用模板都指向 `audio_accel.bit`，而**这个文件不存在**，
     仓库里只有第 ① 步的 `ps_only.bit`。照抄会直接 FileNotFoundError。
  3. 基线数据表把素材采样率写成 48000，实测 `real_voice.wav` 是 **44100**。
     —— 正是这次在修的同一类错，留在那里会让人以为基线素材本来就该按 48k 处理。

  其余九处是"旧参数残留在记叙和示例里"（决策表、技能包的提示词和测试台模板、
  提交清单），都加了带日期的补记，**历史记录本身保留，只标"已被取代"**。

· **AI 的问题（加烟测时判据拍得太紧，等于没加）**

  给位宽扫描脚本加了个"数据是不是同一代"的检查 —— 八行 SNR 极差小于阈值就报警。
  第一版阈值定成 `< 1e-3`。实际极差是 **0.0014**，**没触发**。
  是去手算出精确值才发现阈值不对。
  **判据要按"物理上该差多少"定**：跨位宽该差几十 dB，所以 1 dB 以内就是异常。
  不能拍一个"看起来很严"的数。

· **环境的坑**

  - 这台机器的 conda 里**没有 `soundfile`**，而仓库里好几个脚本都 import 它。
    `scipy` 是有的。加了回退：优先 `soundfile`，没有就用 `scipy.io.wavfile`，
    两条路都写 16 位 PCM —— 免得变成"装了才跑得起来"。
  - 终端是 GBK 代码页，中文输出在日志里看是乱码（文件本身没问题）。
    跑脚本时加 `PYTHONIOENCODING=utf-8` 就正常了。

【怎么修正】

1. **软件基线整体对齐到硬件算法**：重采样到 48 kHz、边界和设计法从 `band_design.py`
   取、压缩曲线对齐核的实现。两边的算法由此变成同一套。

2. **三个系数生成脚本 + 头文件的默认抽头数从 65 改成 193。**
   设计点已经定了 193，而默认值还是 65 —— **不带开关跑就会生成一套对不上固件的系数**。
   改完重跑一遍，产物**逐字节一致**（说明改掉的只是陷阱，现有结果一个没动）。

3. **位宽扫描脚本加两道防护**：一是数据不同代时主动喊出来
   （`fixed_*.txt` 还是 9/29 相减式改造**之前**的核跑出来的，
   八行 SNR 全在 −8.4 dB、极差 0.0014，数字都在"合理范围"里，表面完全看不出来）；
   二是分频段的表头和取值改成从 `BANDS` 生成，不再硬编码旧边界
   （原来的键在边界改了之后全部取不到，会安静地印一整张 nan）。

4. **全仓库通读。** 覆盖仓库全部文档 + 本地那份给非技术视角写的说明，
   逐条对着当前设计读。12 处全部改完，其中历史记录性质的只加"已被取代"标记，
   不改写原文。
