【任务】
为 HLS 加速核准备 C++ 仿真激励（Testbench）和测试数据。

【提示词】
「FIR 的 HLS C++ 仿真怎么接 Python 导出的测试数据？」
「C++ Testbench 读取文本/CSV 测试向量的写法，以及硬件侧验证 FIR 的常规流程？」

【模型回答】
给了一个方向性参考：可在 `sim/hls_csim` 下放 C++ 测试文件，做 FIR 滤波参考逻辑/调用
待验证函数，并从文件读入 Python 导出的数据；建议用 Python 把音频/信号导出为文本文件
供 C++ 读取、再与参考输出做比对。实际落地时仍按 HLS 核接口、定点格式、路径和容差
要求人工调整。

【哪里错了】
本步骤未报错，为纯开发任务。

【怎么修正】
按工程流程手动完成并跑通：
- 在 `sim/hls_csim` 下搭建/调整 C++ Testbench，写/改文件读取、测试向量驱动、FIR 调用、参考结果比对、错误统计与日志输出；
- 用 Python 脚本导出音频或生成信号为文本/CSV 测试数据，统一量化位宽、行列格式、采样顺序；
- 对齐 HLS 加速核接口与仿真预期，设置合理容差/错误计数标准，跑通 csim；

【沉淀】
→ 形成可复用的 HLS C++ Testbench 模板（含“读 Python 导出数据 + 驱动 DUT + 结果比对”
  流程），放进 `skill/templates/` 目录，供后续 HLS 加速核/FPGA 验证复用。
