【任务】编写 Python 软件 FIR 滤波器基线脚本，实现音频滤波与频谱对比可视化。

【提示词】
「帮我用 Python scipy.signal.firwin 设计一个 65 抽头的 FIR 低通滤波器，截止频率 600Hz」
「FFT 频谱图在 0Hz 处有巨大尖峰，完全掩盖了正常的频段，怎么解决？」

【模型回答】
AI 建议使用 scipy 的 firwin 和 lfilter 实现滤波。针对尖峰问题，建议在 FFT 前加入去直流操作 `x = x - np.mean(x)`，并限制坐标轴范围 `plt.xlim`、`plt.ylim`。

【哪里错了】
1. FFT 频谱图在 0Hz 处出现高达 12000 的直流尖峰，掩盖了正常信号。
2. 最初认为只需限制横坐标，后来发现纵坐标也被直流分量撑大了。
3. 绘图时因数据源仅包含左声道（440Hz），两条线完全重合，无法展示滤波效果。

【怎么修正】
1. 加入去直流操作 `x = x - np.mean(x)`。
2. 使用 `plt.xlim(0, 2000)` 和 `plt.ylim(0, 1.5)` 锁定范围。
3. 将输入数据改为左右声道混合（data[:, 0] + data[:, 1]），重新生成频谱图，成功看到 440Hz 被保留、880Hz 被滤除。
