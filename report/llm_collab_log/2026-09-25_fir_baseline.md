【任务】
编写 Python 软件 FIR 滤波器基线脚本，实现音频滤波与频谱对比可视化。

【提示词】
「想用 Python 搭个 FIR 基线，scipy.signal.firwin 整 65 抽头低通、截止 600Hz 行不行？后面还要拿它滤音频、画频谱对比」
「FFT 频谱图在 0Hz 处有巨大尖峰，完全掩盖了正常的频段，怎么解决？」

【模型回答】
AI 给了方向性参考：用 scipy 的 firwin 设计滤波器、用 lfilter 做滤波；针对 0Hz 直流尖峰，建议 FFT 前先去直流（如 `x = x - np.mean(x)`），并配合 `plt.xlim` / `plt.ylim` 限制坐标范围观察有效频段。实际脚本的音频读取、声道处理、量化/采样对齐、绘图比对和阈值判断仍是按实验数据手动调整跑通的，不是直接照搬生成物。

【哪里错了】
1. FFT 在 0Hz 处出现高达 12000 的直流尖峰，把正常信号频段压没了。
2. 一开始只想着截横坐标，后来才发现纵坐标也被直流分量撑大，光限 x 轴不够。
3. 绘图时测试数据只取了左声道（约 440Hz 单频），滤波前后两条线基本重合，看不出滤除效果。

【怎么修正】
1. 加去直流操作 `x = x - np.mean(x)`。
2. 用 `plt.xlim(0, 2000)` 和 `plt.ylim(0, 1.5)` 这类方式锁定显示范围，便于看有效频谱。
3. 输入改成左右声道混合（`data[:, 0] + data[:, 1]`）重新生成频谱图；跑完后能看出440Hz 保留、880Hz 被滤除，和 FIR 低通预期一致。（过程中把 AI 回复当“查手册/要思路”，最终参数、声道拼法、绘图代码和验证结论均人工核对确认。）
