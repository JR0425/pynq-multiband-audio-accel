# 大模型协作日志索引

日志按**工作单元**组织：一个任务一篇，不按时间流水。每篇固定五段 ——
【任务】→【提示词】→【模型回答】→【哪里错了】→【怎么修正】，末尾附【沉淀】与【验证边界】。

写这五段的顺序是有意的：**先写"哪里错了"，再写"怎么修正"**。
把错误放在结果前面，是为了让读的人先看见判断是怎么被推翻的，而不是先看见结论。
【验证边界】记的是这一篇里哪些是推演、哪些真上板量过、哪个数当时还没确认 ——
引用其中任何一条之前，先看那一节。纯进度盘点不作为工作日志收录。

索引按主题分组；跨主题的关联在条目末尾用「见 XXX」标出。
