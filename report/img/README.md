# 截图索引

这个目录存项目过程中的截图。**图里的字是搜不到的**，所以每张图在这里配一行说明
（时间 + 这是什么 + 为什么它重要），引用它的日志里也会再写一遍。

命名规则：纯英文、小写、短横线，编号往后排。

- `log-015-board-audio-loop-run.png` —— 2026-10-06 20:22，板载 Jupyter 里跑

  **第 8 节是六个候选参数逐个放**（响度已和直通对齐）。
  录屏/截图取在第 9 节电平台阶加进去之前，所以画面里没有台阶表 —— 台阶那一节的
