# 基于 PYNQ-Z2 的实时多频段音频处理加速平台设计报告（草稿）

## 一、 选题背景与意义

### 1.1 听力辅助算法的现状与痛点
全球听力损失人口数以亿计，助听算法的核心是多频段动态范围压缩（DRC）。该算法要求极低延迟与实时处理，且需要针对不同患者的听力曲线进行灵活重构。
- 纯软件（如 Python、手机 App）无法满足严苛的实时性要求（延迟通常 > 20ms）。
- 专用 ASIC 芯片流片成本极高、周期极长，不适合算法快速迭代。
- FPGA 凭借其并行计算能力和硬件可重构特性，恰好填补了这一空白。

### 1.2 我们的创新点与场景迁移价值
本项目基于 PYNQ-Z2 平台，利用 HLS 与 RTL 实现多频段 FIR 滤波和动态范围压缩，提供一种低成本、低延迟、可重构的听力辅助算法验证平台。该技术可直接迁移至会议系统、车载语音、直播降噪等场景。

## 二、 系统架构设计

### 2.1 硬件平台介绍
本设计采用 PYNQ-Z2（Zynq-7020）作为核心平台，板载 ADAU1761 音频编解码芯片，提供 I2S 接口进行音频采集与播放。

### 2.2 自建 Overlay 架构
我们放弃了修改官方 base overlay 的路线，转而自建标准 Overlay。音频数据流为：
ADAU1761 -> I2S -> axi_i2s_adi -> AXI-Stream -> FIR加速核 (HLS/RTL) -> axi_i2s_adi -> I2S -> ADAU1761
PS 侧通过 Python 进行 I2C 配置与性能计数读取。
