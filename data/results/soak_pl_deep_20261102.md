# 深度压缩下的长稳（2026-11-02）

11-02 那趟 605 秒长跑用的是演示音源，压缩器全程空闲（进出核峰值恒定）。判据全 PASS 只能说明通路与调度稳定，不能说明压缩器持续工作时也稳。本文补一趟让压缩器全程工作的长跑。

## 配置

- 音源：`tone1001_full.wav`（1 kHz 满幅单音，循环播放）
- 参数：增益 +24 dB，门限 −40 dBFS，压缩比 0.5（即 2:1），attack 5 ms，release 100 ms，MPO −6 dBFS
- 时长：300 秒，每 2 秒采一次，共 150 个采样点
- 探针：`board/probes/soak_pl_600.py --secs 300 --no-start`

## 压缩器确实在工作

| 观察量 | 值 | 说明 |
|---|---|---|
| 进核峰值 | 803（全程恒定） | 满幅音源经板载播放 −32 dB 衰减后的固定电平 |
| 出核峰值 | 7214—7241 | 有起伏，不再是空闲时的恒定值 |
| 有效增益 | 7224 / 803 = **19.08 dB** | 设定 +24 dB，压掉约 **4.9 dB** |
| 二段包络 | −14.4 dBFS | 比门限 −40 dBFS 高 25.6 dB |
| 压缩比读数 | 2.0 | 与设定 0.5（2:1）一致 |

只记 `gr0`（第一段）时读数为 0 是正常的：1 kHz 单音落在第二段，第一段没有信号。

## 判据结果

十项全 PASS（`soak_pl_deep_20261102.json` 为原始逐次采样）：

- 存活：`age` 最大 0.11 s
- 采集 overrun 0 → 0，播放 underrun 恒 0，RX FIFO 溢出与跳变 0
- `ramp_busy` 最终归零，无 stale、无 error
- 温度 53.0—55.1 ℃（首 53.9 → 末 54.9）
- 内存 311—315 MB（无单调增长）

## 边界

- 300 秒，不是 600 秒；结论是「压缩器连续工作时，300 秒内无溢出、无欠载、无泄漏」，不外推到更长。
- 单音不是语音，测的是调度与计数，不是听感，也不覆盖包络快速起伏下的行为。
- 与 605 秒那趟分工不同：那趟证明长时间通路的稳定性，这趟补上「压缩器确实在动」这一条。
