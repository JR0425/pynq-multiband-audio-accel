基础状态(BAD)= PYNQ 的 select_microphone 之后,再写 stream_begin 那 4 个寄存器
(R22=0x21 R24=0x41 R29/R30=0xFB)。这就是 run_live.sh 每次开声的原始状态。

三遍全静(自激被切断)的只有三组:

  hp_driver_off   195 / 173 / 179   耳机功放整个关掉(R29/R30=0x02)
  gain_0dB        154 / 107 / 165   话筒 PGA boost 降到 0 dB(R5/R7=0x08)
  lden_off        264 / 148 / 313   差分输入关掉(R8/R9=0x00)
  gain_m12dB      38 / 143 / 55     同上,再叠输入音量 -12 dB
  gain_p21dB      156 / 142 / 161   同上,再叠输入音量 +21 dB
  (gain_0dB / gain_m12dB / gain_p21dB 都属"boost 降 0 dB",输入音量那三档全静
   → 说明起决定作用的是 PGA 那级 boost,不是输入音量那级)

三遍里至少满一次(没治好)的:

  control_bad     36083 / 46062 / 50716   坏状态本身
  rec_mixer_off   65445 / 140  / 65197    关录音混音器
  playback_off    43037 / 5990 / 47287    把 DAC 摘出播放混音(R22/R24=0x01)
  input_muted     3992  / 1.7  / 3975     录音混音器 boost 静音(有残留 ~4000,
                                          带一个约 1/16 满幅的直流偏移)
  hp_vol_m57dB    145   / 65430 / 150     耳机音量 -57 dB,但功放还开着
  nGate_off       45142 / 48477 / 45703   关噪声门(比基础状态更凶)

=== 三条结论 ===

1. 环路的另一头是耳机功放。
   10-10 记的"环不在耳机那条路上(音量设 0 照样满)"要改:当时的 0 实际是 0x03
   = -57 dB,功放仍然使能;真正把功放关掉(0x02,芯片自己的默认值)才三遍全静。
   所以"跟输出多大无关"是对的,但原因是**只要功放开着就够**,和信号电平无关。

2. 环路增益只是刚刚超过 1。
   两头各砍一刀都能断;hp_vol_m57dB 那一档开始出现"三遍里满一次"的双稳态,
   probe5 里"同一个寄存器值有时啸有时静"就是这么来的。

3. probe3 的 G 行(R8/R9 归零就治好)不是"那个寄存器是开关",而是"总增益掉到 1
   以下"。同理 R5/R7 降 20 dB 也断,而且更划算 —— 差分输入那级 +21 dB 还在。

=== 修法 ===
board/scripts/fir_live.py 选完麦克风之后加:
    lib.stream_reg_write(0x0B, 0x08, IIC)   # R5 左,boost +20 dB -> 0 dB
    lib.stream_reg_write(0x0D, 0x08, IIC)   # R7 右
话筒 +41 dB -> +21 dB,听的那一头完全不动。

=== 顺带 ===
rec_mixer_off 与 nGate_off 冲到接近满幅方波(mean ≈ 半幅),而 input_muted 只剩
一个带直流偏移的小残留 —— 这两组测出来的"照样满"里,有多少是自激、有多少是
关掉混音器之后 ADC 输入悬空本身的产物,cap_probe7 没能分开。它们都不影响
上面那两条结论:那是**唯一**能让它停下来的一组(耳机功放 / 话筒增益),
其余全都没停。
