# 端到端电学环回尝试（2026-11-02）

## 目的

报告里的端到端延迟一直是分解值：核群 96 采样（1.966 ms，抓取窗口互相关实测）
+ 声学 1.23 ms（2026-10-22 耳机贴话筒实测）。前者是数字段，后者已经包含
DAC 重建、空气、ADC 抗混叠。11-02 想用一根电学环回线（DAC → 线 → ADC）
单独量一次模拟段，和 1.23 ms 互相核对。

## 做法

探针 `board/probes/loopback_delay.py`：

1. 停 `fir-pl-webui`，载入交付位流 `fir_pl.bit`（MD5 `628b75b3…`），
   `codec_init()` 后把输入 PGA 设为指定档。
2. `ctrl[3]=1` 打开 PL 内部方波（250 Hz，`tone_sel=0`），输出端完全旁路处理链。
   先试连续方波看电平，再改用 0.7 ms 单脉冲测沿（连续方波每 2 ms 一个沿，
   第一沿太弱时会把第二沿当成第一沿，lag 一次多 98 采样）。
3. 抓取窗口（0x78/0x7C）读最新 1024 点：高 16 位 = 出核 `mpo_l`，
   低 16 位 = 进核 `fe_din_q`。出核第一个沿到进核第一个沿的差就是
   DAC + 线 + ADC 的往返延迟。
4. 扫幅度 300—30000 计数，输入 PGA 试 `0x03`（−12 dB）、`0xFF`（+35.25 dB，
   加固定 +20 dB boost 共 +55.25 dB）、`0xFE`（单端、+35.25 dB）；
   输入选择试 `select_mic` 和 `select_line_in`。

## 读数

| 条件 | 出核峰值 | 进核峰值 | 说明 |
|---|---|---|---|
| `--pga 0x03`，MIC，amp 300/1000/3000 | 300/1000/3000 | 1/1/2 | 基本是本底 |
| `--pga 0xFF`，MIC，单脉冲 amp 3000/10000/20000/30000 | 3000—30000 | 71/78/59/36 | 没有随幅度增长的回声 |
| `--pga 0xFF`，MIC，连续方波 amp 3000/10000/20000 | 3000/10000/20000 | 111/54/101 | 仍在本底量级，不是 8% 的串扰 |
| `--pga 0xFE`（单端），MIC，连续方波 amp 1000/3000/10000 | 1000/3000/10000 | 0/0/1 | 单端更小 |
| `--input line`，amp 3000—30000 | 3000—30000 | 40/6/3/1 | 线路输入也没有 |

出核那一路始终正确：写 300 就抓到 300，写 30000 就抓到 30000，说明
PL → I2S → codec DAC 的数字侧和 `ctrl[3]` 测试音都正常。进核那一路在
最大输入增益下只有几十个计数，且不随测试音幅度增长，判定为**没有收到环回信号**。

## 一个容易误读的现象

服务在放 `voice_20261031_184837.wav` 时，网页 `/api/status` 的 `peak_in`
会跟着 `peak_out` 成固定比例（约 0.079，−22 dB）。这不是话筒收到的回声：
播放时 `fir_pl_live` 把音源切到波表（`ctrl[5]`），`fe_din` 读的就是波表数据，
不是 ADC。测电学环回必须停服务、清掉 `ctrl[5]`，否则会把音源当成话筒输入。

## 判断

- 数字侧、DAC 侧、抓取窗口都正常。
- ADC 侧在 MIC / LINE、差分 / 单端、低增益 / 最大增益下都没有收到耳机输出的信号。
- 最可能的原因在物理连接，而不是软件：
  1. 板子耳机座的 U41（TS3A226AE）只在插头插入上升沿检测一次，可能没锁到
     分线器的 MIC 触点；实测有时要拔插到第 18—35 秒电平才跳。
  2. 分线器的“话筒”口可能不是接到板子的 MIC 触点（有些分线器是双耳机口，
     或 CTIA/OMTP 定义相反）。
  3. 短接线是 TRS 时，耳机左/右两声道的信号会落到话筒的正/负两端；
     若 PGA 是差分模式（`0x400E` bit0=1），同相的两路会相减抵消。
     本次单端 `0xFE` 也没有信号，所以这一条不是唯一原因，但换线时要注意。

## 结论怎么用

这次没有拿到可用的环回读数，**不改变报告里的延迟口径**：
仍然是「核群 1.966 ms 实测 + 声学 1.23 ms 实测」，两项都是板上实测，
声学那项已经包含 DAC/ADC 转换。等环回线确认接通后可以重跑本探针，
把模拟段单独量一次作为交叉核对；在那之前不写“端到端环回已实测”。
