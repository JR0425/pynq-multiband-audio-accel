# THD+N 复测：默认门限下压缩器并未启动（2026-11-02，PYNQ-Z2 板上）

位流 `628b75b3d7a13015a69125fb8ac2d228`（与交付位流一致），服务 `fir_pl_live.py` 在线。
探针 `board/probes/thdn.py`，1024 点 Hann 窗 FFT，统计除基波外全部 bin，每档 3 帧取中位。

## 为什么重测

2026-10-31 的 `thdn_localization_20261031.md` 把 9.13% 标成「演示默认（22 dB / −20 dBFS / 0.7）」，
但代码里的默认门限是 **−10 dBFS**（`board/scripts/fir_pl_webui.py:76`）。两个口径对不上。

重测时又发现第二处口径漂移：2026-11-01 的提交给板载 WAV 播放加了 **−32 dB 固定衰减**
（`board/scripts/fir_pl_live.py` 的 `PLAY_GAIN_DB = -32.0`），10-31 那批数是在加这个衰减之前测的。
所以本轮用满幅音源，把入核电平拉回可比区间。

## 音源

`wav/tone1001_full.wav`：1 kHz（21 × 48828.125 / 1024 = 1001.36 Hz，正好落在 FFT bin 上）、
峰值 32000、48.828 kHz、2 秒。经 −32 dB 播放衰减后**入核峰值 803 计数（−32.2 dBFS）**。
生成方式：

```python
import numpy as np, wave, math
fs = 48828; f = 21 * 48828.125 / 1024.0; n = int(fs * 2)
x = np.round(32000 * np.sin(2 * math.pi * f * np.arange(n) / fs)).astype('<i2')
with wave.open("tone1001_full.wav", "wb") as w:
    w.setnchannels(1); w.setsampwidth(2); w.setframerate(fs); w.writeframes(x.tobytes())
```

## 七档对照

| # | 段增益 | 门限 | 压缩比 | 出核峰值 | THD+N |
|---|---|---|---|---|---|
| 1 | +24 dB | 0 dBFS（压缩关闭） | — | 12727 | **0.09%** |
| 2 | +22 dB（默认） | −10 dBFS（默认） | 0.7（默认） | 10110 | **0.09%** |
| 3 | +24 dB | −10 dBFS | 0.7 | 12727 | 0.09% |
| 4 | +30 dB | −10 dBFS | 0.7 | 23782 | 2.36% |
| 5 | +36 dB | −10 dBFS | 0.7 | 27669（限幅） | 48.4% |
| 6 | +24 dB | −20 dBFS | 0.7 | 11195 | **9.32%** |
| 7 | +24 dB | −40 dBFS | 0.5 | 7225 | **37.24%** |

输入 THD 全程 0.09%（第 1、2、3 档），说明 0.09% 是输入本底，定点前端链不引入可测失真。

## 判读

1. **默认参数（+22 / −10 / 0.7）下压缩器没有启动**，THD+N 0.09%，等于输入本底。
2. 10-31 的 9.13% 实际对应第 6 档（门限 −20 dBFS），本轮复现为 9.32%，同量级。
3. 失真随压缩深度单调上升：门限每降 10 dB、增益每升 6 dB，THD 从 0.09% → 2.4% → 9.3% → 37%。
4. 第 5 档 48% 是限幅器动作，不是压缩器的数，不能与 1—4 档并列。
5. 机制仍是 `src/rtl/fir_drc4.v:262-266` 的 `y = sign(a)·max(0, |a| − gr)` 零交叉死区。

## 复现

```bash
# 1) 上传满幅音源（只需一次）
python board/probes/board_ssh.py --put tone1001_full.wav /home/xilinx/dma_exp/wav/tone1001_full.wav

# 2) 设参数（/api/tune 会把没带的字段重置成默认，每次发全五个）
curl -X POST http://192.168.2.99:8080/api/tune -H "Content-Type: application/json" \
  -d '{"gain_db":[22,22,22,22],"thr_db":[-10,-10,-10,-10],"ratio":[0.7,0.7,0.7,0.7],"attack_ms":[5,5,5,5],"release_ms":[100,100,100,100]}'

# 3) 量
python board/probes/board_ssh.py --sudo \
  "cd /home/xilinx/dma_exp && XILINX_XRT=/usr /usr/local/share/pynq-venv/bin/python3 -u thdn.py --wav wav/tone1001_full.wav --loop 3 --tag demo_default"
```

测完把音源切回演示 WAV，并把参数恢复到默认。
