# data/results 索引

本目录是**所有实测读数**的落盘处。文件名带日期，代表测的那天；同一件事可能测过好几次，
**以本文件「当前结论」那一栏指定的文件为准**，其余是历史或被推翻的记录。

本目录有两条线，读数的时候先分清是哪一条：

- **块模式（上一代）**：位流 `v25_env_indep`（`fir.bit`，36 拍/采样、205/220 DSP、WNS +0.533 ns、
  md5 `5aa079f29e8d66c21d1d34f1302c3695`），演示档 16.2 ms（L=360 / NBUF=2）。
- **PL 直连（当前演示）**：位流 `fir_pl.bit`（md5 `628b75b3…`、213/220 DSP、WNS **+0.090**、
  0 失败端点），音频不经过 PS。凡是写 213 DSP 的读数都属于这条线，不要和 205 混着说。

`data/results/` 里带日期的文件，以「当前结论」那一栏指定的为准。
凡是版本号写 `v18`/`v19`/`v20`/`v21` 的读数都不是当前演示版的数。

## 引用口径

- **加速比 16.7×** 必须同时带四条限定：同一块芯片；ARM 侧是 float64 / scipy，PL 侧是 Q1.15；ARM 6.117 µs/采样（3.41× 实时），核 0.367 µs/采样（56.77× 实时）；不与手写 NEON 的 CPU 实现比。
- **12.5×（`v21_wdrc`，49 拍）和 19.5×（`v19`，31 拍）只作历史对照**，不能当当前数字。
- **soak 分两条线**：块模式是 10-23 两趟 600 秒（均 0 丢块）加 10-24 补测（0 丢块），见 `soak600_20261023.md`；PL 直连是 E3（10-29，606 s）、T9（10-31）与 11-02 复测（605.4 s）三趟，判据是溢出/欠载/跳变计数零增长，见 `soak_pl_600_20261029_1031.md` 与 `soak_pl_20261102.json`。10-17 的 59,478 块 / 丢 539 / 0.991× 是板挂排查那趟，不是 soak。
- **THD+N 引用要带门限**：代码默认门限是 −10 dBFS，默认参数下压缩器不启动、THD 等于输入本底 0.09%；9.13%/9.32% 对应 −20 dBFS，37.24% 对应 −40 dBFS 深压。板载 WAV 播放自 11-01 起有 −32 dB 固定衰减，测 THD 要用满幅音源把入核电平拉回 803 计数，否则读数不可比。见 `thdn_20261102.md`。
- **WDRC A/B（10-19）**：8,926 块 / 89.26 s / 90.05 s / 丢 78 块，以 `fir_wdrc_ab_run_20261019.txt` 为准。
- **RTL 的 3 拍/采样、25.7 M 采样/秒（约 536×）只描述自研实验位流**，演示走 `fir_pl.bit` 的 PL 直连链路；这几个数不能和 16.7× 并列（测的不是同一件事），也不能和块模式那张 46× 并列（那张的大头是 PS 逐字 MMIO，不是核）。
- **DMA / 全 PL 直连那一组（10-25）自带一套口径**：`14.4~14.8 ms` 和 `10.1 ms` 是板上实测，`2.3 ms` 是**推算**（按各级 FIFO 水位 + 核内拍数 + codec 固定转换时延预算出来的，没有端到端实测）。这三个数都不能和**块模式演示档的嘴到耳 `16.2 ms`**（L=360/NBUF=2，`fir.bit`）、**DMA 实验线的整块墙钟 `2.17 ms`**（4800 点一块，测的是搬运不是嘴到耳）、**核单独 `56.77×`**（只算核内拍数）混着说 —— 四个数的起止点各不相同。除 `fir_pl.bit` 外的四颗**没做过人耳验收** —— 10-25 当晚连当时的 `fir.bit` 都放不出声，问题在耳机 / 插座 / codec 输出那一段，不在 PL。
